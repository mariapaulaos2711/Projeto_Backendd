# Atividade 08 — CRUD com JavaScript

## Objetivo
Desenvolver operações CRUD utilizando JavaScript, Node.js e Express, manipulando dados armazenados em arquivos JSON.

## Funcionalidades
- CRUD de clientes, pedidos, produtos e itens.
- Cadastro, listagem, alteração e exclusão de registros.
- Relacionamento entre clientes, pedidos, produtos e itens.
- Cálculo do subtotal dos itens.
- Cálculo do total de cada pedido com a função `calcTotais`.

## Tecnologias utilizadas
- JavaScript
- Node.js
- Express
- JSON
- Thunder Client
- Git e GitHub

## Conclusão
A atividade permitiu praticar operações CRUD, relacionamentos entre dados e cálculos utilizando JavaScript, além de testar as rotas com o Thunder Client.
